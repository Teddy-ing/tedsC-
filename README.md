# Ted's C# and ASP.NET learning project

A portable guided learning workspace. Prepared November 8, 2026. Desktop setup and Session 1's checkpoint are complete; Session 2 is next. See PROGRESS.md for current setup results and the next step.

## Move it to the desktop

1. Copy or extract this entire folder to a location on your desktop PC, for example a folder named `Ted Csharp Learning` in Documents. Keep it separate from the career-planning project.
2. Open that folder as your local project in Codex. The folder containing this README and AGENTS.md should be the project root. Start a chat there.
3. Paste the setup prompt below. No past chat, laptop path or account integration is needed. Code and exercises will be created on that PC when the lessons need them.

The files in this folder are the portable record. Moving them transfers the written plan and notes; do not assume chat history or unsaved editor changes transfer with them. Continue using the desktop copy as the current learning record.

## Prompt 1 — set up, then begin

```text
This project's purpose is to teach me C# and ASP.NET. Read AGENTS.md and the learning documents. Briefly confirm the teaching rules and where we are starting. Inspect this desktop's tools and prepare only what Session 1 needs, preserving anything already here. Record setup results. Then give me the first short C# reading/prediction exercise and wait for my answer. Do not solve it or build the MVC app yet. I have about an hour, including setup.
```

## Prompt 2 — resume on another day or in a new chat

```text
Read AGENTS.md, PROGRESS.md and the latest learning-log entry. Resume my C#/ASP.NET learning from the saved next step. I have about an hour. Start with one short recall check, then guide me through one task at a time. Save actual evidence and where to resume.
```

## Prompt 3 — discuss something I read or brought in

```text
I want to study this resource or code: [paste URL or project-relative path]. Read our teaching instructions and inspect the material. Connect one small part to my current learning goal. Ask me to trace or explain it before giving your explanation, then guide one small modification. Record the source and what I actually demonstrated. Preserve the original code.
```

## Prompt 4 — work a ticket when ready

```text
Read our plan and progress. Prepare a working small MVC baseline for the next ticket if one is not ready, and verify it runs. Give me the ticket's behavior and acceptance criteria. Let me locate the relevant code and explain an approach before helping implement it. Leave the ticket unsolved until we work through it together. Check the result with me and record my contribution and AI assistance separately.
```

For a short day: `I have 20 minutes and low energy. Resume from PROGRESS.md with one manageable exercise, then save a stopping point.`

To stop: `Wrap up here. Save what I tried, what help I needed, what we checked, any open question, and the exact next step. Do not start another task.`

## First two weeks

Four roughly hour-long sessions per week, with up to an optional extra hour for setup or review. The plan starts when you start; there are no missed calendar deadlines. Reading, talking through code, writing small pieces yourself, and AI-assisted changes all count. The goal is to understand and change one small application with increasing confidence and evidence.

AGENTS.md supplies persistent project guidance; keeping it at this project's root and checking the loaded instructions in the first chat follows [official OpenAI guidance](https://learn.chatgpt.com/docs/agent-configuration/agents-md), checked November 8, 2026. If the wrong instructions appear, verify the opened folder and any applicable override files before beginning.
